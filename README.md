# 03 · Grilla — ion-grid · row · col

Sistema de 12 columnas en cuatro secciones:

1. **12 columnas** — cada `ion-row` reparte el ancho con `size` (suma 12).
2. **Responsive** — `size-md` / `size-lg`: el ancho cambia según la pantalla.
3. **Offset** — empuja la columna dejando espacio a su izquierda, sin columnas vacías.
4. **Alineación** — `ion-justify-content-*` (horizontal) e `ion-align-items-*` (vertical).

**Archivo clave:** `src/app/grilla/grilla.page.html`
